# Sales Forecasting & Business Intelligence Dashboard

## 📊 Project Overview

This project analyzes sales data using **SQL Server, Python, and Power BI** to understand business performance and forecast future sales.

The project combines data analysis, data visualization, and time-series forecasting to provide useful business insights through an interactive Power BI dashboard.

---

## 🎯 Objectives

- Analyze overall sales and profit performance
- Identify sales trends over time
- Compare sales across categories and regions
- Analyze order quantity and customer-related information
- Forecast sales for the next 6 months
- Build an interactive Business Intelligence dashboard

---

## 🛠️ Technologies Used

- **Python**
  - Pandas
  - Matplotlib
  - Statsmodels
  - ARIMA

- **SQL Server**
  - Data storage
  - Data analysis
  - SQL queries
  - Aggregations

- **Power BI**
  - Data visualization
  - KPI dashboards
  - Sales trend analysis
  - Sales forecasting visualization
