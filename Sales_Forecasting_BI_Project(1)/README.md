# Sales Forecasting & Business Intelligence Dashboard

## Stack
SQL Server + Python (Pandas, Statsmodels, Matplotlib) + Power BI

## Project Flow
CSV -> SQL cleaning/analysis -> Python EDA & ARIMA forecasting -> Power BI dashboard

## Dashboard Pages
1. Executive Overview
2. Sales Analysis
3. Sales Forecasting
4. Business Insights

## Dataset
Synthetic 6,000-order dataset covering 2023-2025. It is designed for portfolio/learning use.

## How to run
1. Import `data/sales_data.csv` into SQL Server and create the `SalesDB` table using `sql/create_database.sql`.
2. Run `sql/analysis_queries.sql`.
3. From the `python` folder run:
   `pip install pandas matplotlib statsmodels`
   `python sales_forecasting.py`
4. Open Power BI Desktop and connect to SQL Server, then add `data/forecast_results.csv`.
5. Create the measures in `powerbi/DAX_Measures.txt`.
6. Build the four dashboard pages described above.

## Note
The `.pbix` file cannot be generated by this environment because Power BI Desktop is a proprietary application. The folder contains all source data, SQL, Python, DAX, and setup instructions needed to build the working PBIX locally.
